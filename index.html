CIMD Dynamic App Registration POC

Simulates an MCP client authenticating with Box via CIMD — token exchange + API call happen on devpod (same origin, no CORS), results return via postMessage.

Configuration

OAuth Flow Idle

  1. Generate PKCE code_verifier + code_challenge
  2. Open /authorize with metadata URL as client_id
  3. User logs in + grants consent (Box native)
  4. Devpod callback exchanges code for token (same origin)
  5. Devpod callback calls Box API (same origin)
  6. Results returned via postMessage
